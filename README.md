# ALU Regex Data Extraction Project

## Overview
This project uses Python and Regex to extract and clean data such as emails, URLs, phone numbers, and credit cards from raw text.

## Features
- Email extraction and validation  
- URL filtering  
- Phone number extraction  
- Credit card masking for security  

## Tools Used
- Python 3  
- Regular Expressions (re)  
- JSON  

## Output
The program generates a structured JSON file with all extracted data.
